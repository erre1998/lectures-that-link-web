# Lectures that Link – Web Application

This repository contains the web application for the research project **“Lectures that Link”**, which analyzes European lecture series as nodes of interaction within the Digital Humanities (DH) community.

The web application complements the original research repository by making its data and quantitative analyses accessible through a browser-based interface. The underlying research data and scripts remain the work of the Lectures that Link project and its contributors.
